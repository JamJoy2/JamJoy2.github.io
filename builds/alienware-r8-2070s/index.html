About this build

Why it's built like this

Freshly serviced Alienware Aurora R8, fully tested and ready to game. The CPU and GPU have both been repasted, the whole system has been cleaned out, and it's running a freshly activated Windows 11 Pro install with the latest drivers. The RTX 2070 Super makes this a really capable 1080p machine: expect 150+ fps in Fortnite, Valorant and CS2, around 100+ fps in Apex and Warzone, and smooth 60+ fps in games like GTA V, Elden Ring and Cyberpunk with DLSS.
